# Ресурсоэффективное дообучение визуально-языковой модели Qwen2-VL-2B (QLoRA)

## Цель проекта
Адаптировать компактную предварительно обученную визуально-языковую модель (VLM) для улучшения качества ответов на русскоязычные визуальные запросы в условиях жестких ограничений вычислительных ресурсов (бесплатный уровень Google Colab), с последующей объективной сравнительной оценкой на стандартизированном бенчмарке.

## Задачи
1. Выбор базовой архитектуры модели (~2B параметров), совместимой с ограничениями VRAM GPU T4 (16 ГБ).
2. Подготовка и репрезентативное сэмплирование открытых датасетов VK для балансировки качества обучения и лимитов времени выполнения сессии.
3. Реализация пайплайна дообучения с использованием метода QLoRA (4-битное квантование) и оптимизацией потребления памяти.
4. Проведение сравнительной оценки производительности базовой и дообученной модели на бенчмарке MMBench-ru.
5. Документирование процесса, результатов и инженерных компромиссов решения.

## Использование открытых данных VK
В проекте использованы данные из официальной коллекции `deepvk/vision-language-modeling`:
- **Для обучения:** Датасет `deepvk/LLaVA-Instruct-ru`. Ввиду ограничения времени непрерывной работы бесплатной сессии Google Colab, из полного набора была взята случайная репрезентативная подвыборка объемом **1000 записей** (`seed=42`). Это позволило завершить полный цикл дообучения без прерывания сессии из-за таймаута.
- **Для оценки:** Датасет `deepvk/mmbench-ru` (сплит `dev`). Для оперативного сравнения baseline и finetuned версий в рамках скрипта оценка проводилась на **100 примерах**, что достаточно для демонстрации работоспособности пайплайна и получения сравнительных метрик.
- *Инфраструктурно:* Скрипт также предусматривает загрузку и кэширование изображений COCO в Google Drive для ускорения I/O операций, если они требуются конкретными записями датасета.

## Как запустить решение
1. Откройте файл `untitled2_gpu.ipynb` (или соответствующий `.py` скрипт) в Google Colab.
2. Убедитесь, что в настройках выбран ускоритель GPU (T4 или выше): *Среда выполнения → Изменить тип среды выполнения → T4 GPU*.
3. Выполните первую ячейку для установки зависимостей (`transformers`, `peft`, `bitsandbytes`, `trl` и др.).
4. **Важно:** После установки зависимостей выполните *Среда выполнения → Перезапустить среду выполнения*, чтобы сбросить кэш импортов.
5. Запускайте ячейки последовательно. Скрипт автоматически:
   - Смонтирует Google Drive.
   - Загрузит и подготовит данные.
   - Запустит обучение с QLoRA.
   - Проведет оценку базовой и дообученной модели.
   - Сохранит веса адаптера в папку `./qwen2vl-2b-ru-lora-final` и метрики в `evaluation_results.json`.
