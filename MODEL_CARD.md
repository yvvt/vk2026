# Описание модели: Qwen2-VL-2B-Instruct-ru-QLoRA-1k

## Детали модели
- **Базовая архитектура:** `Qwen/Qwen2-VL-2B-Instruct`
- **Метод адаптации:** QLoRA (Quantized Low-Rank Adaptation)
- **Конфигурация квантования:** 4-bit (`nf4`), `bnb_4bit_use_double_quant=True`, `bnb_4bit_compute_dtype=torch.bfloat16`
- **Параметры LoRA:** 
  - `r=8`
  - `lora_alpha=16`
  - `lora_dropout=0.05`
  - `target_modules`: `["q_proj", "k_proj", "v_proj", "o_proj", "gate_proj", "up_proj", "down_proj"]`
  - `bias`: "none"

## Данные для обучения
- **Источник:** `deepvk/LLaVA-Instruct-ru` (Hugging Face)
- **Объем использованных данных:** 1000 пар изображение-инструкция (случайная подвыборка из оригинального набора с фиксированным `seed=42`).
- **Предобработка:** Изображения приводятся к формату PIL RGB. Текстовые сообщения форматируются через `apply_chat_template` с явным указанием модальности `{"type": "image"}` и `{"type": "text"}`. Маска потерь (loss mask) применяется только к токенам ответа ассистента (prompt tokens masked with `-100`).

## Ограничения и рекомендации по использованию
1. **Масштаб данных:** Модель дообучалась на ограниченной подвыборке (1000 примеров). Она демонстрирует адаптацию к формату русских инструкций, но подвержена риску катастрофического забывания (catastrophic forgetting) общих знаний.
2. **Зависимости:** Для загрузки модели требуется наличие библиотек `peft` и `bitsandbytes`. Веса сохранены как адаптер; для инференса без базовой модели требуется операция `merge_and_unload()` (как реализовано в скрипте оценки).
3. **Назначение:** Модель предназначена для исследовательских целей и демонстрации работоспособности пайплайна в условиях ограниченных ресурсов. Не рекомендуется для продакшн-использования без дополнительного выравнивания (alignment) и оценки на полном тестовом наборе.
